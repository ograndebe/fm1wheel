fm1-wheel on the SMK-37

The same tonewheel chain, now with 37 keys, 16 pads and four faders. The middle 27 keys are the FM-1's F3–G5; the faders edit drawbars page by page.

Before you install

The SMK-37 has a factory calibration that cannot be downloaded again. Make a full flash backup first and keep M-VAVE's stock package for the way back.

Build

One app, two boards

make smk37 writes app/build/smk37/fm1-wheel-smk37.fwsc. The FM-1 build is unchanged. The SMK board layer is selected by BOARD=smk37; there is no second app or DSP copy.

Install

Command line

Use the SMK-37 browser installer in Chrome/Edge, or python3 fm1-base/tools/fm1_install.py app/build/smk37/fm1-wheel-smk37-{{VERSION}}.fwsc / a compatible SMK updater. Never cross-flash FM-1 and SMK packages.

Safety

Protected flash

The boot head, Bluetooth/calibration, stock resources and key/MAC areas are never written by this build. Read SMK37.md before the first install.

Drawbars, faders and pads

Values stay 0–8, with 8 fully out and the bars filling from the top down. The four faders are the last four bars: 2', 1⅗', 1⅓', 1'. The five rightmost pad columns are the first five: the top pad pushes a bar in and the bottom pad pulls it out, one step per tap. Faders are absolute and reversed: minimum = fully out, maximum = fully in.

Pads 1–3 and 9–11 recall presets 1–6; the K8 PRESETS encoder has all eight. The pad/fader drawbars are always on; GLOBE does not toggle them, and the keys keep playing.

Backup

Backup não incluído neste build

Este firmware guarda os ajustes e as registrações na flash do FM-1 com o botão SAVE. A ferramenta de backup/restore do fm1-base não está habilitada nesta versão.

Use SAVE no painel para gravar os ajustes. Para voltar ao firmware oficial ou recuperar o aparelho, use o instalador e as ferramentas de recuperação indicadas no manual.

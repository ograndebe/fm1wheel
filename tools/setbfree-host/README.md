# setBfree host tools

Host-only tools built from the **unmodified** setBfree DSP. They are not part
of the firmware. GPL-2.0-or-later; see `../../LICENSING.md`.

| Tool | What |
|---|---|
| `refrender` | Renders a text script through setBfree's chain (tonegen → preamp → reverb → whirl) to a float32 WAV. The "golden" side of the A/B tests. Scripts: `events/chord.txt`, `drawbars.txt`, `percussion.txt`, `vib.txt`, `leslie.txt`, `drive.txt`, `demo.txt`. |
| `dump_tables` | Dumps wheel frequencies/attenuations, the key-contact matrix, the key-compression curve and the click envelopes as a C header for the firmware. |
| `dump_whirl.sh` | Copies setBfree's whirl at 1,024 displacement positions and writes `app/dsp/whirl_tables.h` (Doppler/reflection/filter tables). |

## Build

```sh
make -C tools/setbfree-host
make -C tools/setbfree-host check     # summary + every events/*.txt -> build/*.wav
```

The Makefile compiles the original files from `third_party/setBfree/` and
`host.c`, a stub for the globals and MIDI-control registration that normally
come from JACK/LV2. No setBfree file is patched.

## refrender script

One event per line; `#` starts a comment. Events apply at the next 128-sample
block (2.9 ms at 44.1 kHz), as they will on the FM-1.

```
drawbars U 888000000     # upper/lower/pedal (U/L/P), 9 digits 0..8
swell 127                # 0..127
perc on|off
perc harmonic 2|3
perc decay fast|slow
perc volume normal|soft
vib off|v1|c1|v2|c2|v3|c3
vib route off|upper|lower|both
drive 0..127             # 0 = clean preamp
reverb 0..127
leslie stop|slow|fast
noteon 1 60 100          # channel 1 upper, 2 lower, 3 pedals
noteoff 1 60
wait 500                 # advance the timeline (ms)
```

Options: `--gain G`, `--tail MS` (default 500), `--sr HZ`, `--dry` (tonegen
only), `--preamp` (tonegen + preamp), `--reverb` (tonegen + preamp + reverb,
no Leslie). The default is the full chain (tonegen + preamp + reverb + Leslie;
what `make compare` uses).

## Tables

```sh
tools/setbfree-host/dump_tables --summary
tools/setbfree-host/dump_tables --header app/dsp/organ_tables.h
```

The generated header is GPL-2.0-or-later. It is regenerated by the build; do
not edit it. `wb_contrib[].level` is Q24 (divide by 16777216.0f), because the
taper sums reach ~2.2 while the crosstalk levels go down to ~4e-5.

## Measured (Apple Silicon, host only)

| Measurement | Value |
|---|---|
| 1 note (888000000) | 18 active wheels |
| 3 notes | 54 active wheels |
| 9 notes | 91 active wheels |
| Key contributions (154 keys) | 20,488 (max 194/key) |
| setBfree wavetables @44.1 kHz | 603.8 KB float / 301.9 KB int16 |
| `struct b_whirl` original (16,384 positions) | 929 KB |
| `struct b_whirl` at 1,024 positions | 89 KB, -50.2 dB vs. original |

These numbers drive the memory plan in `PLANO.md`. Host timings are not device
timings; measure on the FM-1 before choosing the final table sizes.

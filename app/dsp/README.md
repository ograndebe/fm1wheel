# app/dsp — Phase 1

The organ DSP lands here. Planned files (all GPL-3.0-or-later):

| File | Origin | Notes |
|---|---|---|
| `organ.c/.h` | port of setBfree `src/tonegen.c` | 91 wheels as phase accumulators + a shared sine table; drawbars, key matrix, key compression, click, percussion |
| `vibrato.c/.h` | port of setBfree `src/vibrato.c` | scanner delay line; V1–V3 / C1–C3 |
| `preamp.c/.h` | port of setBfree `b_overdrive/` | clean bypass + preamp character |
| `reverb.c/.h` | port of setBfree `b_reverb/` | Schroeder reverb |
| `whirl.c/.h` | port of setBfree `b_whirl/` | Leslie; use 1,024 displacement positions (~89 KB) |
| `organ_tables.h` | generated by `tools/setbfree-host/dump_tables` | wheel increments/attenuation, key matrix, envelopes; not edited by hand |

Rules:

- No `double` in the firmware runtime (fm1-base's build checks it). All
  double-precision math stays in the host generator.
- No `malloc` in the audio path; static/pool allocation.
- 128-sample blocks; the engine is called from `app_render`.
- Keep the setBfree copyright/licence headers in the ported files and record
  every deviation in `PATCHES.md`.
- The first acceptance test is A/B against `tools/setbfree-host/refrender` on
  the same event script.

Phase 0 deliberately contains none of this: the app is still fm1-base's
template, so the platform, host simulator and reference tools can be validated
before the DSP port starts.

# app/dsp — Phase 1

The organ DSP lives here. All files are GPL-3.0-or-later.

| File | Origin | Status |
|---|---|---|
| `organ.c/.h` | port of setBfree `src/tonegen.c` | **done (dry)**: 91 phase-accumulator wheels + shared sine table, key matrix, drawbars, key compression, click envelopes, percussion |
| `organ_tables.h` | generated by `tools/setbfree-host/dump_tables` | committed: wheel increments/attenuation, key matrix, envelopes; regenerate with `make tables` |
| `vibrato.c/.h` | port of setBfree `src/vibrato.c` | **done**: scanner V1–V3 / C1–C3 |
| `preamp.c/.h` | port of setBfree `b_overdrive/` | **done**: clean bypass + 4x-oversampled overdrive |
| `reverb.c/.h` | port of setBfree `b_reverb/` | **done**: Schroeder reverb, 79 KB delay pool in `.pool` |
| `whirl.c/.h` | port of setBfree `b_whirl/` | next: Leslie with 1,024 displacement positions (~89 KB) |

Rules:

- No `double` in the firmware runtime (fm1-base's build checks it). All
  double-precision math stays in the host generator.
- No `malloc` in the audio path; static/pool allocation.
- 128-sample blocks; the engine is called from `app_render`.
- Keep the setBfree copyright/licence headers in the ported files and record
  every deviation in `PATCHES.md`.
- The first acceptance test is A/B against `tools/setbfree-host/refrender` on
  the same event script: `make compare`.

A/B (2026-10-23, the engine against setBfree's `oscGenerateFragment` + scanner):
chord correlation 0.99995 / null -40 dB; percussion 0.9996 / -31 dB; scanner
(V1 → C1 → V3) 0.9815 / -14.3 dB (the scanner is a modulated delay, so a few
samples of phase decorrelate the null; the bands are ±0.5 dB up to 1.6 kHz).
The Leslie is the next slice.

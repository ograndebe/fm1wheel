# WheelBox — manual (draft)

**Phase 0 placeholder.** The firmware still runs fm1-base's template app, so
this manual describes nothing final yet. It is replaced in Phase 3, when the
organ UI exists.

What the finished manual will cover:

1. Install and recovery
2. The screen: registration, drawbars, percussion, vibrato/chorus, drive,
   reverb, Leslie
3. The 27-key keyboard, octave shift and the MIDI channels (upper/lower/pedal)
4. MIDI CC map and program change (setBfree compatible)
5. Presets and saving
6. USB audio and MIDI
7. Troubleshooting and recovery

The analysis, scope and roadmap are in `../PLANO.md`.

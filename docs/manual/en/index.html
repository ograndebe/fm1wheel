fm1-wheel — hardware manual

Português · English

Tonewheel organ firmware for the M-VAVE FM-1, derived from setBfree, running on fm1-base.

Status: the firmware builds for the FM-1 and passes the build checks, but it has not been tested on hardware yet. The host simulator and the web emulator run the full chain (tone generator, scanner, preamp, reverb and Leslie). This manual describes the intended/implemented behaviour; keyboard and performance details may change after the first device test.

1Install

The firmware is installed over USB-MIDI. Connect the FM-1 with a USB data cable and close any other application using its MIDI ports.

make device          # builds app/build/fm1-wheel.fwsc
make install         # shows the device and asks before writing

You can also use the project's web installer (Chrome/Edge) or run fm1_install.py directly. Installing firmware is at your own risk. Keep the official firmware and the recovery tools (fm1-base/bsp/tools/fm1_rescue.py, FM-1-transporter) at hand.

If the install is interrupted, the FM-1 stays in update mode and the same command finishes the write. To go back to the official firmware, use M-VAVE's updater or the web installer.

2Power on and play

The FM-1 has 27 keys (F3–G5), 7 encoders, 14 buttons, a MASTER pot and a 240×240 screen.

  • The keys play the upper manual by default.
  • OCT- / OCT+ transpose the built-in keyboard by up to ±2 octaves. External MIDI is not transposed by these buttons.
  • The MASTER pot controls the output level.
  • An external MIDI controller (USB or TRS) can play any manual; see section 5.

The screen shows:

  • header: name, the note that is sounding, and CPU load;
  • body: selected manual, registration, percussion, vibrato and the nine drawbar columns with the 16', 5⅓', 8', 4', 2⅔', 2', 1⅗', 1⅓', 1' footages;
  • footer: octave, page, volume, rotor, SAVE state, drive and reverb.

4Drawbar-key mode (the keyboard as a controller)

GLO turns on/off the mode in which the 27 keys stop playing and edit the drawbars of the selected manual. It is the equivalent of the programming mode on older clonewheel organs.

  • Mode on: the built-in keys do not play; each press raises or lowers one drawbar by one position. External MIDI keeps playing — you can play from a controller and use the FM-1 keyboard to edit the registration.
  • Mode off: the keys play normally again.
  • The mode is not saved: it starts off at the next boot.
  • Drawbar changes mark SAVE; press SAVE to store them.

Key map

Each pair flat (black key) / natural (white key) controls one drawbar:

PairDrawbarAction
F#3 / G316'F# up, G down
G#3 / A35⅓'G# up, A down
A#3 / B38'A# up, B down
C#4 / D44'C# up, D down
D#4 / E42⅔'D# up, E down
F#4 / G42'F# up, G down
G#4 / A41⅗'G# up, A down
A#4 / B41⅓'A# up, B down
C#5 / D51'C# up, D down
  • F3, C4, F4 and C5 are ignored.
  • D#5, E5, F5, F#5 and G5 are free (no function in this version).
  • In drawbar mode all 18 control keys light equally; the ignored/free keys stay dark. The key position (black = up, white = down) shows the direction.
  • Each press changes one step (0..8). The value appears in the corresponding column on the screen; at 0 or 8 the key does not go past the limit.
  • The edited manual is the one shown at the top of the screen (UPPER/LOWER/PEDAL); use EDIT or the ALGO encoder to change it.

To play from the built-in keyboard again, press GLO again. If a key is held while switching, it is released and only sounds again after being released and pressed again.

Program Change 0–7 selects one of the eight registrations.

The drawbar map is setBfree's (inverted: 0 = maximum). An external drawbar controller works without extra configuration, including in drawbar-key mode.

6What is saved

SAVE writes to flash:

  • the octave;
  • the swell;
  • all 27 drawbars (upper/lower/pedal);
  • percussion (on/off, 2nd/3rd, fast/slow);
  • the selected registration;
  • vibrato (mode);
  • drive and character;
  • reverb;
  • rotor (stop/slow/fast).

Not saved: drawbar-key mode, the edit page and the selected manual (they return to their defaults at boot).

7Troubleshooting

SymptomWhat to check
No soundMASTER, audio cable, PLAY/rotor, amplifier volume; in drawbar mode the keys do not play (press GLO)
Keys do not playdrawbar-key mode is on (GLO lit)
Stuck noterelease and press the key again; if it persists, power-cycle the FM-1
External MIDI does not playchannel 1/2/3, USB data cable, another app using the port
Installer cannot find the FM-1USB data cable, close DAWs/MIDI apps; check fm1_install.py --info
Install interruptedreconnect and run make install again; the FM-1 stays in update mode
Distorted soundlower MASTER, drive or the registration (FULL); the app's limiter acts on peaks

8Development

make build-host      # host simulator
make test-host       # app tests (keys, drawbars, MIDI, persistence)
make web             # browser emulator (Emscripten)
make serve-web       # http://localhost:8790/
make compare         # A/B against setBfree
make device          # firmware for the FM-1
make install         # writes it to the connected FM-1

The web emulator runs the same C code as the firmware; use Cmd+Shift+R to load a new wasm after make web.

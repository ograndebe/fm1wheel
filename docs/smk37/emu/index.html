fm1-wheel · SMK-37 emulator

A compact SMK-37 panel for the same WebAssembly app. Sound starts after you press Start. Back to the SMK-37 page · Manual

Press Start to boot.

Keys are C3–C6. Pads 1–8 recall registrations; pads 9–11 select fader pages A–C; faders 1–4 edit the four values on the current page. Drag the faders or wheels; use the +/− buttons for the encoders.

The emulator uses the host simulator and the same app/DSP as the firmware. It is not a cycle-accurate CPU emulator. A physical SMK-37 is still needed for the final hardware check.

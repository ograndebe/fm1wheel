M-VAVE SMK-37 Pro · órgão tonewheel · after setBfree

fm1-wheel no SMK-37

A mesma cadeia tonewheel, agora com 37 teclas, 16 pads e quatro faders. As 27 teclas do meio são as F3–G5 do FM-1; os faders editam os drawbars página por página.

Baixar .fwsc (0.2.0) Instalar no navegador Experimentar o emulador Build e segurança

Versão 0.2.0 · build e testes de host passam · teste no SMK-37 físico pendente.

Antes de instalar

O SMK-37 tem uma calibração de fábrica que não pode ser baixada de novo. Faça um backup completo do flash primeiro e guarde o pacote oficial da M-VAVE para voltar.

Build

Um app, duas placas

make smk37 gera app/build/smk37/fm1-wheel-smk37.fwsc. O build do FM-1 não muda. A camada do SMK é escolhida por BOARD=smk37; não há um segundo app nem uma cópia do DSP.

Instalação

Linha de comando

Use o instalador SMK-37 no navegador no Chrome/Edge, ou python3 fm1-base/tools/fm1_install.py app/build/smk37/fm1-wheel-smk37-0.2.0.fwsc / um atualizador compatível do SMK. Nunca instale pacote de FM-1 no SMK nem o contrário.

Segurança

Flash protegido

O cabeçalho de boot, Bluetooth/calibração, recursos oficiais e a área de key/MAC nunca são gravados por este build. Leia o SMK37.md antes da primeira instalação.

Drawbars, página por página

Os valores continuam 0–8, com 8 todo puxado e as barras enchendo de cima para baixo. Os faders usam soft takeover: depois de trocar a página ou o preset, só movem a barra quando chegam ao valor atual.

FADER BANK ou os pads 9–11 escolhem a página. Os pads 1–8 chamam as registrações de fábrica. GLOBE liga/desliga os faders/pads; as teclas continuam tocando.

O build do SMK compila e passa nos testes de host; ainda não foi gravado em uma unidade física. A primeira instalação é um bring-up. O emulador SMK-37 no navegador roda o mesmo app pelo simulador de host; não é um emulador de CPU ciclo a ciclo.

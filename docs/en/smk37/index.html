fm1-wheel on the SMK-37

The same tonewheel chain, now with 37 keys, 16 pads and four faders. The middle 27 keys are the FM-1's F3–G5; the faders edit drawbars page by page.

Download .fwsc (0.2.0) Install in browser Try the emulator Build and safety

Version 0.2.0 · build and host tests pass · physical SMK-37 test pending.

Before you install

The SMK-37 has a factory calibration that cannot be downloaded again. Make a full flash backup first and keep M-VAVE's stock package for the way back.

Build

One app, two boards

make smk37 writes app/build/smk37/fm1-wheel-smk37.fwsc. The FM-1 build is unchanged. The SMK board layer is selected by BOARD=smk37; there is no second app or DSP copy.

Install

Command line

Use the SMK-37 browser installer in Chrome/Edge, or python3 fm1-base/tools/fm1_install.py app/build/smk37/fm1-wheel-smk37-0.2.0.fwsc / a compatible SMK updater. Never cross-flash FM-1 and SMK packages.

Safety

Protected flash

The boot head, Bluetooth/calibration, stock resources and key/MAC areas are never written by this build. Read SMK37.md before the first install.

Drawbars, page by page

Values stay 0–8, with 8 fully out and the bars filling from the top down. Faders use soft takeover: after a page or preset change they only move a bar when they reach its current value.

FADER BANK or pads 9–11 select the page. Pads 1–8 recall the factory registrations. GLOBE turns the fader/pad controls on and off; the keys keep playing.
